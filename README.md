# Neon Bay 3D

Jeu 3D en monde ouvert, conçu pour être lancé dans un navigateur.

## Lancer le jeu

Le fichier principal attendu est `index.html`. Pour publier le jeu avec GitHub Pages :

1. Téléversez le fichier du jeu `neon-bay-3d.html` dans ce dépôt.
2. Renommez-le en `index.html` (ou gardez une copie sous ce nom).
3. Ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis `main` et `/(root)`.
5. Enregistrez et attendez la publication.

## Remarques

- Le jeu peut nécessiter une connexion Internet si des bibliothèques sont chargées depuis un CDN.
- Testez d'abord sur téléphone et réduisez les effets ou la qualité graphique si les performances sont faibles.
